# Apoorva Lambat portfolio draft

A standalone, responsive HTML/CSS/JavaScript portfolio inspired by Vishal's portfolio layout. The original portfolio project is unchanged.

## Editing
- `dist/index.html`: page content and placeholders.
- `dist/styles.css`: light/dark themes, responsive cards and layout.
- `dist/app.js`: project detail copy, theme switching, filters, tabs and dialogs.

## Add before public release
- Approved resume PDF.
- Exact professional headline, role titles, employment dates and contributions.
- Degree titles, institutions, department, grades, thesis and supervisor.
- Original project imagery, methodology, individual contribution, results and report links.
- Verified tools, methods, certifications, publications and interests.
- Preferred public email and opportunity preferences.
- Award paper title and contribution.

Dashed boxes visibly mark missing content. The resume buttons open a placeholder notice instead of a fake PDF. Project artwork is illustrative and labelled as such. The B&V marker is text, not an official company logo.
